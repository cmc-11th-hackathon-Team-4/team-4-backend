# 0003. Redis 는 ElastiCache 대신 EC2 에 직접 설치

- 상태: 대체됨(→ [0010](0010-remove-redis.md))
- 날짜: 2026-11-21 (PR #8)

## 배경

Redis 를 쓰기로 했다. 용도는 아직 정해지지 않았다 (캐시, 토큰 저장 등 후보).

## 결정

- 운영: 앱과 같은 EC2 에 `redis-server` 설치 (`scripts/ec2-setup.sh`). `127.0.0.1:6379` 에만 바인딩, 보안 그룹에 6379 를 열지 않는다.
- 앱은 Spring 기본값(`localhost:6379`)으로 연결하므로 운영 설정·Secrets 변경이 없다.
- 로컬: docker-compose `redis:7.4`, 호스트 포트 6380.

## 결과

- 추가 비용이 없다.
- 서버 메모리를 앱과 나눠 쓴다. 서버(인스턴스)를 교체하면 Redis 데이터도 사라진다. 그래서 잃으면 안 되는 데이터는 Redis 에만 두지 않는 것을 권장한다 (용도가 정해질 때 다시 결정).
- 용도가 정해지면 키 이름 규칙과 TTL 원칙을 AGENTS.md 에 추가한다.
