# 0011. 서버에 탄력적 IP 연결

- 상태: 채택
- 날짜: 2026-11-22

## 배경

[ADR 0004](0004-no-elastic-ip.md) 에서는 자동 할당 공인 IP 를 임시로 썼다. 인스턴스를 중지 → 시작하면 IP 가 바뀌어 DuckDNS 를 매번 다시 맞춰야 했다.

## 결정

- 탄력적 IP 를 할당해 운영 EC2 에 연결한다.
- DuckDNS(`niturnnaeturn.duckdns.org`) 의 A 레코드는 이 탄력적 IP 를 가리킨다.

## 결과

- 인스턴스를 중지 → 시작해도 IP 가 바뀌지 않아 DuckDNS 를 다시 갱신할 필요가 없다.
- 인스턴스에 연결된 동안에도 퍼블릭 IPv4 요금이 나온다. 인스턴스를 없앨 때는 탄력적 IP 도 해제해야 요금이 멈춘다.
