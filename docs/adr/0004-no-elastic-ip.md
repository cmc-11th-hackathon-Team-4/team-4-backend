# 0004. 탄력적 IP 없이 자동 할당 공인 IP 사용

- 상태: 채택 (임시)
- 날짜: 2026-11-21

## 배경

배포 가이드는 탄력적 IP 할당을 전제로 했지만, 확인해 보니 계정에 할당된 탄력적 IP 가 없고 서버는 자동 할당 공인 IP 를 쓰고 있었다.

## 결정

해커톤 기간에는 그대로 둔다.

## 결과

- 인스턴스를 **중지 → 시작** 하면 IP 가 바뀐다 (재부팅은 괜찮다). 그러면 DuckDNS 의 IP 를 새 IP 로 바꿔야 한다.
- 해커톤 이후에도 운영한다면 탄력적 IP 를 할당해 연결한다 (연결하는 순간 IP 가 바뀌므로 DuckDNS 도 함께 갱신).
