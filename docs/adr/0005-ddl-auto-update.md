# 0005. 스키마는 Flyway 없이 `ddl-auto: update`

- 상태: 채택
- 날짜: 2026-11-21 (AGENTS.md 에 명시. 원래 결정의 근거는 기록돼 있지 않다)

## 결정

- 테이블은 Hibernate `ddl-auto: update` 가 엔티티를 보고 만든다. 마이그레이션 도구(Flyway)는 쓰지 않는다.
- 운영 데이터베이스가 없으면 앱이 시작할 때 만든다 (`createDatabaseIfNotExist=true`, PR #5).

## 결과

- 엔티티만 추가하면 테이블·컬럼이 자동으로 생긴다.
- **컬럼 이름 변경·삭제, 테이블 삭제는 반영되지 않는다.** 엔티티에서 지워도 DB 에 남는다 → 필요하면 DB 에서 직접 정리한다 (예: `[TEST]` 도메인을 지울 때 `test_item` 테이블).
- 타입 변경은 운영 데이터를 깨뜨릴 수 있으니 PR 에 명시하고 신중히 한다.
- 운영 데이터를 지켜야 하는 시점이 오면 Flyway 도입을 다시 검토한다.
